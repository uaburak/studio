# agent/

Bu klasör, üretim ajanının (Claude Agent SDK) çalışma zamanındaki çalışma alanı olacak:

- `skills/` — ajanın kullanacağı skill'ler (üçüncü taraf skill'ler buraya kopyalanır, değişiklikleri diff olarak incelenir; bkz. PLAN.md §10–11)
- `brands/` — marka klasörleri (marka profili, marka kiti, örnek içerikler)

Şimdilik boş. Kod içermez ve pnpm çalışma alanına dahil değildir. İçeriği Faz 1 görevleri (F1-3, F1-4) belirleyecek.
